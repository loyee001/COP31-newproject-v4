# 绿茵计划 ShadePath · 产品说明文档

> 版本 v1.0 · 2026-11-14
> AI for Climate 青年气候黑客松（ATOX × 观猹）参赛项目 · 赛道：气候适应与校园韧性
> 交付形态：单文件交互网页 + Godot 4.3 第一视角演示

## 1. 产品概述

### 1.1 一句话定位

对「教室门 → 食堂门」这条 208 米、约 3 分钟的步行路线做**真实太阳几何模拟**，回答一个可计算的问题：**在有限预算下，把树种在哪里，换来的荫凉最划算**——并让人第一视角走进去验证。

### 1.2 问题背景

| 维度 | 定义 |
|---|---|
| 谁 | 中午 11:50–12:50 离开教室走向食堂的学生（约 200–400 人/天，高峰集中在 20 分钟） |
| 在哪 | 教学楼门 → 食堂门，208 m 步行路线，中段为几乎无树冠的开阔前庭 |
| 什么时候 | 夏季正午前后，太阳高度角 70° 以上 |
| 问题 | 基线遮荫率仅 16%，暴晒段体感约 38 °C，落在 UTCI「强/极强热应激」区间 |
| 约束 | 不能移动建筑、不能加空调、不能改路线；**唯一能动的变量是遮荫**，预算量级 $2,000–2,200 |

于是「气候适应」被压缩成一个纯粹的优化问题：有限预算下的最优种植布局。

### 1.3 产品理念

- **可计算、可验证、可体验**：几何 → 太阳 → 阴影 → 暴露 → 优化 → 第一视角，每一环都可被质疑、替换与实测校准。
- **工具出数、模型出话**：所有数字由确定性物理模型求解，AI 用于问题定义、方案生成与自然语言解释。
- **模型估算与实测严格区分**：全部结论标注「模型输出，非实测」，局限清单随交付物公开。

### 1.4 目标用户

| 用户 | 使用方式 |
|---|---|
| 黑客松评委 | 3 分钟演示动线：拖预算 → 地图长树 → 第一视角走一遍 → 热量结算 |
| 校园后勤 / 园林决策者 | 预算-收益权衡工具：每美元换到的加权荫凉分钟数、拐点省钱方案 |
| 学生 / 教育者 | 第一视角体验热暴露与树荫差异，理解微干预的价值 |
| 开发者 | 零依赖单文件网页 + 程序化 Godot 工程，几何数据可 diff、可替换 |

- **URL 哈希深链**：`#budget`、`#sun` 等直达视图，刷新后保持当前页签。

## 4. Godot 第一视角演示（主演示）

### 4.1 演示流程

启动即演示：UE 风格白色小人（1.80 m，位移驱动步态，脚不打滑）自动从教室门走向食堂，默认第三人称跟随镜头。HUD 实时显示脚下体感 UTCI；到达食堂自动弹出**全程热量结算**。

### 4.2 操作键位

| 键 | 作用 |
|---|---|
| `W A S D` / 方向键 | 手动接管行走；`Shift` 加速 |
| `V` | 第一 / 第三人称切换 |
| `B` | **一键切换种植前 / 种植后**：同一位置同一时刻，37.8 °C 暴晒 ⇄ 32.0 °C 树荫 |
| `O` | **算法现场重算种植方案**：贪心集合覆盖 + 拐点截断，树木 / 阴影 / 小地图 / HUD 同步刷新 |
| `P` / `R` | 暂停 / 从起点重走 |
| `[` / `]` | 时钟 ∓15 分钟 |
| `M` / `G` | 小地图 / 地面光照分区 显示开关 |
| `Esc` | 释放鼠标 |

### 4.3 核心体验点

- **地面光照分区**：阳光区暖色、树荫青绿、建筑阴影偏蓝；按当前太阳方向解析投影（建筑凸包扫掠 + 树冠精确椭圆），调时钟、换方案即刻重绘，阴影方向与长度跟着太阳走。
- **右上小地图**：建筑、路线（已走 / 未走分色）、树、起点、终点与行者朝向同步显示；终点设发光地标（脉冲地环 + 柔光柱 + 始终朝向镜头的「终点 · CANTEEN」标牌）。
- **阴影判定用物理射线**：每帧从玩家眼位向太阳发射线，命中树冠 / 建筑 / 无命中分别判定树荫 / 建筑阴影 / 暴晒——阴影是几何算出来的，不是贴图。
- **终点热量账本**：累计热负荷 = Σ max(UTCI − 26 °C, 0) × 真实步行时间（1.15 m/s 口径，非演示压缩时间）；同时给出「若无荫凉全程暴晒」反事实对照与降幅、荫凉占比、≥38 °C 暴露时长、峰值体感；`R` 重走或 `B` 换方案后面板显示两轮对比。

### 4.4 调试命令行参数（写在 `--` 之后）

`--shot=<路径>.png`、`--shotat=<帧>`、`--shotend=1`、`--start=<米>`、`--clock=<分钟>`、`--fp=1`、`--noplan=1`、`--opt=1`（启动即应用拐点方案）、`--budget=<美元>`。

## 5. 算法与数据模型

### 5.1 方法链

```
校园几何 ──▶ 太阳位置 ──▶ 阴影投影 ──▶ 步行暴露剖面 ──▶ 预算优化 ──▶ 第一视角体验
 (CAD/BIM)   (NOAA)      (凸包/椭圆)   (逐采样点)     (贪心集合覆盖)   (Godot)
```

### 5.2 核心算法

1. **太阳位置（NOAA / Michalsky）**：儒略日 → 几何平黄经 → 均时差 → 时角 → 高度角 / 方位角；处理经度时差、时区、蒙气差、日出日落。
2. **阴影几何**：建筑 = 底面与顶面沿光线位移后的凸包；树冠 = 半长轴 `r / sin(高度角)`、中心偏移 `h / tan(高度角)` 的精确椭圆。
3. **暴露剖面**：路线每 0.5 m 采样，按 1.15 m/s 推进，每个采样点按**抵达时刻**重解天气与遮荫（太阳在步行过程中移动）。
4. **预算优化（贪心集合覆盖）**：元素 = 路段采样 × 出发时段（11:50 / 12:20 / 12:50，人流权重 0.25 / 0.45 / 0.30，各切 5 个时间片）；权重 = 人流 × 停留分钟数；候选点沿步道每 8 m、两侧各 3.5 m，避开建筑与现有树；每棵 $95（含三年养护），按「加权荫凉分钟数 / 美元」逐棵挑选。只在无人时段遮荫的树得分为零。
5. **热环境代理式**：`UTCI ≈ Ta + 0.12·e − 1.05·v + 0.45·(Tmrt − Ta)`，系数公开；**是代理式而非官方六阶多项式**，结论只用遮荫段与暴晒段的差值。

### 5.3 拐点截断：最少预算近最优

满预算 $2,200 选出 **23 棵 / $2,185**；在收益曲线拐点截断（保留约 91% 加权荫凉）得 **18 棵 / $1,710**——12:20 步行遮荫率 81%，省 22% 预算。Godot 内按 `O` 约 0.15 s 即算即用。

### 5.4 数据契约 `campus.json`

坐标约定 x 东 / y 北，单位米；字段 `buildings`（轮廓 + 高度）、`trees`（位置 + 树高 + 冠幅）、`route`（折线）。网页优化器导出可直接覆盖 Godot 数据；Godot 场景全部程序化生成，几何可 diff、可替换为真实校园 glTF。

## 6. 关键结论（模型估算，非实测）

| 指标 | 种植前 | 种植后（23 棵 / $2,185） |
|---|---|---|
| 步行时段路线遮荫率 | 16 % | **87 %** |
| 步行平均体感 UTCI | 36.9 °C | **32.9 °C**（−4.1 °C） |
| 峰值路段体感 UTCI | 38.6 °C | 38.6 °C（暴晒段不变，物理事实） |
| 高温暴露分钟数（≥38 °C） | — | 0.1 min |

拐点方案：18 棵 / $1,710，遮荫率 81%，保留 91% 加权荫凉。

> 声明：天气、人流、校园几何均为合成数据；太阳几何、阴影投影与热代理式为真实公式。所有数字是模型输出，不是实测。

## 7. 快速开始

### 7.1 普通用户

1. **看演示**：双击 `启动演示.bat`（或桌面「绿茵计划 ShadePath 交互预览」快捷方式走网页形态）。
2. **玩网页**：双击 `启动网页预览.bat` —— 自动起桥并打开浏览器；页面内可一键唤起 Godot。
3. 直接双击 `ShadePath-preview.html` 也可浏览全部网页功能，仅「启动 Godot」按钮需要桥。

### 7.2 开发者

```powershell
# 重建网页（src/ → preview/ 与根目录双副本）
powershell -ExecutionPolicy Bypass -File .\build.ps1

# 直接跑 Godot 工程
.\runtime\Godot_v4.3-stable_win64.exe --path .\godot --resolution 1280x720
```

亦可用 Godot 编辑器打开 `godot/`，F5 运行（首次自动导入资源）。

### 7.3 运行环境

- 网页：任意现代浏览器，零依赖、可离线。
- Godot：Windows x64；已在 **Godot 4.3.stable / Vulkan / Intel Iris Xe** 本机实跑并出图验证；便携运行时随包附带，免安装。

- `/ping` 返回 `{ok, godot}`（运行时是否存在）；`/launch` 以引号包裹工程路径启动 Godot（兼容含空格与中文的路径），日志写入 `launcher/bridge.log`、`godot_out.log`、`godot_err.log`。

## 9. 接入真实校园

1. 从 CAD / BIM 导出校园模型（`.glb` / `.gltf`）。
2. 建筑轮廓与高度 → `campus.json.buildings`；现有树 → `trees`；路线折线 → `route`。
3. 网页「路线与预算 → 导出 campus.json」覆盖 `godot/data/campus.json`，或游戏内按 `O` 就地重算。
4. Godot 侧可整体导入 glTF 替换程序化生成（详见 `godot/README.md`）。

## 10. 已知局限与路线图

**局限（随提交材料公开）**

- 校园几何为占位布局，真实结论需贵校 CAD/BIM 与实测树高。
- 天气为合成日变化曲线，不是预报，未接气象 API。
- 热环境为简化代理式，只用差值、不用绝对值。
- 未建模：树冠多年生长、蒸腾降温、地表反射率、局地风场。
- 尚未实测验证。

**路线图**

1. 路线布 5–10 个温湿度记录仪，做种植前后对照实测。
2. 接入气象 API 与真实校园几何。
3. 树冠生长 / 蒸腾等长期效应建模。
4. 路演物料：60 s 无解说录屏 + 30 s 解说版、PPTX/PDF、英文路演稿与答辩口径。

## 11. 常见问题

| 问题 | 处理 |
|---|---|
| 网页「启动 Godot」提示未检测到桥 | 改用 `启动网页预览.bat` 或桌面快捷方式打开；直接双击 HTML 没有桥 |
| Godot 窗口未弹出 | 确认 `runtime/` 与启动脚本同目录（约 127 MB，勿删）；查看 `launcher/godot_err.log` |
| 桥是否常驻 | 空闲 30 分钟自动退出；需要时重跑 `启动网页预览.bat` |
| 修改了 src 但网页没变 | 运行 `build.ps1` 重建双副本 |
| 数字与体感不符 | 全部为模型估算（合成天气 + 占位几何），见第 6、10 节声明 |

## 附录 A · 术语表

| 术语 | 含义 |
|---|---|
| UTCI | 通用热气候指数，体感温度口径；本项目使用公开系数的简化代理式 |
| Tmrt | 平均辐射温度，阴影/暴晒差异的主要来源 |
| 遮荫率 | 步行时段内处于树荫或建筑阴影的时间占比 |
| 热负荷 | Σ max(UTCI − 26 °C, 0) × 真实步行时间，26 °C 为无热应激上限 |
| 贪心集合覆盖 | 每步买下「加权荫凉分钟数 / 美元」最高的树，直至预算用尽 |
| 拐点方案 | 在边际收益曲线拐点截断的最少预算近最优方案（保留约 91% 加权荫凉） |
| NOAA 太阳算法 | 美国海洋大气管理局的太阳位置解析算法，含均时差与蒙气差修正 |
